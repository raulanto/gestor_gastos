# Gestor de gastos Personales


# 1. Gastos diarios/mensuales (core)

- **Registro rápido**: monto, categoría, cuenta (efectivo/tarjeta/banco), fecha, nota, foto de recibo opcional.
- **Categorías jerárquicas** (padre/hijo) personalizables, con ícono y color.
- **Multi-cuenta** con saldo independiente por cuenta.
- **Gastos recurrentes** (renta, suscripciones, servicios) que se autogeneran cada periodo.
- **Vistas**: día, semana, mes, con totales y comparación contra el periodo anterior.
- **Split de gastos** (dividir un gasto entre varias categorías, ej. súper con comida + limpieza).

# 2. Caja de ahorros

- **Metas de ahorro**: nombre, monto objetivo, fecha límite, ícono.
- **Aportaciones manuales o reglas automáticas** (redondeo de gastos, % fijo de cada ingreso, "ahorro programado" tipo domiciliación).
- **Retiros con motivo obligatorio** (para que no se use como cuenta corriente disfrazada).
- **Progreso visual** (barra/%, proyección de fecha estimada de cumplimiento según ritmo de aportación).
- **Historial de movimientos por meta**.


# 3. Planificación de gastos (presupuestos)

- **Presupuesto mensual por categoría**, con alertas al 80%/100% del límite.
- **Comparativo presupuestado vs. real**, por categoría y global.
- **Planificación de gastos futuros no recurrentes** (viaje, compra grande) con "ahorro objetivo" ligado a una meta de la caja de ahorros.
- **Proyección simple** basada en promedio histórico (3-6 meses) para sugerir presupuesto del próximo mes.


# 4. Ingresos (complemento necesario)

- **Registro de ingresos** (salario, freelance, extra), recurrentes o únicos.
- **Balance neto** = ingresos - gastos, por periodo.
